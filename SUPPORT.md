# Support

For usage questions, start with the documentation:

- [Getting started](docs/getting-started.md)
- [Configuration](docs/configuration.md)
- [Fastify integration](docs/fastify.md)
- [Transports](docs/transports.md)
- [Troubleshooting](docs/troubleshooting.md)
- [API reference](docs/api.md)

For a reproducible defect, open a [bug report](https://github.com/abdou-da0wew/violin/issues/new?template=bug_report.yml). For a proposed capability, open a [feature request](https://github.com/abdou-da0wew/violin/issues/new?template=feature_request.yml).

Please include versions and a minimal reproduction, and remove credentials and personal data from all output. Security issues must be reported privately as described in [SECURITY.md](SECURITY.md).
