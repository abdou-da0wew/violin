# Changelog

## 0.1.0 - 2026-11-01

- Initial standalone Violin package extracted and generalized from Triecbot's error and logger utilities.
- Added structured logger, configurable levels, bindings, child loggers, and secret redaction.
- Added console, bounded JSONL file, and Discord webhook transports.
- Added Fastify logger adapter and application error utilities.
- Added TypeScript ESM/CommonJS build and documentation.
